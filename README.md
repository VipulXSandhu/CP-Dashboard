# CP-Dashboard

A feature-rich Chrome Extension Dashboard designed specifically for Competitive Programmers. Keep track of upcoming contests, solve problems with AI hints, and stay updated with tech news and internship opportunities right from your new tab page.

## Features
- **Contest Tracker:** Live updates for upcoming contests on Codeforces, LeetCode, and CodeChef.
- **Smart Reminders:** Get notified 15 minutes before a contest starts.
- **AI Upsolving:** Ask AI for hints on past unsolved problems using Gemini.
- **Developer Tools:** Built-in Todo lists, tech news feeds, and hackathon/internship tracking.
- **Customizable Dashboard:** Light/Dark mode, Lunar Phase Clock, and profile lock system.

## Installation
1. Clone or download this repository.
2. Open Chrome and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right.
4. Click **Load unpacked** and select the `CSES_Extension` folder.
5. Open a new tab to see your dashboard!

## API Key (Optional)
To use the AI hinting feature, you will need a free Gemini API key. You can add this securely in the extension's Settings menu.
